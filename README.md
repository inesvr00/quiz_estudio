# Quiz Estudio

Aplicacion Flask para estudiar preguntas desde `preguntas.csv` y guardar estadisticas en `stats.db`.

## Instalacion

```powershell
.\.venv\Scripts\python.exe -m pip install -e .
```

## Ejecutar

```powershell
.\.venv\Scripts\python.exe run.py
```

## Rutas principales

- `/`
- `/quiz`
- `/otra-mas`
- `/reiniciar`
- `/estadisticas`
- `/preguntas-falladas`
- `/preguntas-no-hechas`
- `/importar-preguntas`
